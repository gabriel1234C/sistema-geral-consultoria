# Sistema Geral de Consultoria

Simulador de financiamento habitacional e fluxo da construtora, para rodar de graça no Streamlit.

Arquivo principal: `app.py`.

## Colocar no ar (grátis)

1. Entre em [share.streamlit.io](https://share.streamlit.io) com a mesma conta GitHub.
2. Clique em **Create app**.
3. Repositório: `sistema-geral-consultoria`. Branch: `main`. Main file: `app.py`.
4. Clique em **Deploy**. O link que aparecer é o sistema no ar.

O repositório precisa continuar **público**. O plano gratuito do Streamlit não publica repositório privado.
